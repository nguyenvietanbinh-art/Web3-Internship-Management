# Giao diện và thao tác theo vai trò

Đã kiểm browser thật: form đối chiếu một card, kỳ/phương pháp/topK1–20, Enter, ngăn gửi trùng, giữ lựa chọn, xóa kết quả cũ; bảo mật tài khoản/modal mật khẩu; task criteria/draft/evidence/phiên bản; giảng viên đọc bài/chấm riêng; Admin rubric/chốt điểm; sinh viên chỉ thấy điểm sau công bố.

Vai trò doanh nghiệp không có menu AI ranking; Admin/Giảng viên không có liên kết ví/MetaMask trong hồ sơ. Session shared cùng browser profile: đổi tài khoản ở tab khác làm UI cập nhật đúng vai trò, logout làm các tab bỏ menu riêng. Muốn đăng nhập bốn vai trò đồng thời nên dùng bốn profile trình duyệt, không bốn tab chung session.
